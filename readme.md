# Portfólio — Davi Falabella

Portfólio pessoal com projetos de apps mobile, IoT, Big Data e web. Bilíngue (PT/EN).

**Site:** [davi7071.github.io/portfolio1](https://davi7071.github.io/portfolio1/)

## Tecnologias
- HTML • CSS • JavaScript • Bootstrap 5
- AOS, Isotope, GLightbox, Swiper e Typed.js

## Estrutura
- `index.html` — página principal (sobre, habilidades, portfólio e contato)
- `portfolio-*.html` e `admin-panel.html` — detalhes de cada projeto
- `assets/js/i18n.js` — traduções PT/EN; o texto em português fica no próprio HTML e o inglês em `window.PAGE_I18N`. A escolha de idioma fica salva no navegador.
- `assets/css/main.css` — estilos do template + ajustes no fim do arquivo

Baseado no template [iPortfolio](https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/) da BootstrapMade.
