Sobre o projeto

O Dispositivo IoT de Feedback por Som é um projeto interativo que utiliza um ESP32 para responder a sons específicos configurados por um app mobile feito em React Native. Quando o som definido é detectado (como palmas ou assobio), o dispositivo aciona um servo motor, acende um LED e dispara um buzzer — fornecendo feedback tátil, visual e auditivo. Compacto e versátil, é perfeito para protótipos de automação residencial, ferramentas de acessibilidade ou brinquedos inteligentes.
