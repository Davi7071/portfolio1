Sobre o projeto

De-Fato é um app multiplataforma desenvolvido com Expo e React Native que permite autenticação via Firebase, visualização e edição de notícias por uma interface intuitiva. Conta também com um verificador de notícias por IA, que ajuda a identificar desinformação e garante a qualidade do conteúdo curado. Além disso, o app possui um algoritmo inteligente que recebe um arquivo JSON com as principais notícias da semana e exibe uma barra de relevância dinâmica, que se preenche em tempo real conforme o jornalista escreve uma nova matéria, indicando o quão relevante ela tende a ser.
